# 原始参考资料

此目录保存历史操作手册和环境分布表，供后续人工整理为 `knowledge/docs/` 下的脱敏 Markdown。

## 当前文件

- `木流操作手册.xlsx`：旧版 Muliu 操作参考；可能包含门户、账号或人员相关信息，已被 Git 忽略。
- `服务器环境分布.xlsx`：服务器环境与分布参考；可能包含环境定位、服务器占用或剧本归属信息，已被 Git 忽略。

## 使用规则

- 不直接将整个 Excel 文件内容拼入 AI prompt。
- 整理前先检查是否包含账号、密码、Token、内网地址、数据库地址、服务器 IP 或其他敏感信息。
- 面向 AI 的资料应只保留完成问答或执行计划所需的最小信息；环境定位或敏感配置应拆分、脱敏后再写入 Markdown。
- 原件不是机器人可执行脚本资料；允许执行的脚本仍须单独登记在 `config/muliu_script_catalog.md`。
