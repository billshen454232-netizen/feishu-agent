# clear_logic_game.py

## 资料状态

此脚本阅读副本包含数据库认证和内部连接信息，因此**不作为 AI 可读源码，也不提供调用命令**。本说明仅保留脱敏的业务用途和风险边界。

## 业务用途

脚本用于清理与指定测试服相关的逻辑游戏数据，并处理公共账号数据中与该测试服关联的角色信息。

## 实际影响

**破坏性数据操作。** 它会删除或解除关联的业务数据；错误目标、错误环境或重复执行都可能造成无法从脚本自身恢复的数据损失。
