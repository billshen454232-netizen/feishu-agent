# 脚本调用关系与安全边界

## 资料边界

本说明记录可见脚本之间的概念依赖，不包含内部地址、数据库连接、账号、凭据或目录外工具实现细节。脚本阅读副本不能替代 Linux 已部署版本。

**是否允许机器人执行，唯一以 [../../config/muliu_script_catalog.md](../../config/muliu_script_catalog.md) 的精确合同为准。** 本文不维护第二套“已登记 / 不登记”判断，也不将 catalog 说成远端已部署事实。

## 脚本类别

|类别|涉及资料|主要影响|资料使用重点|
|---|---|---|---|
|基础状态查询|`basic_info.sh`|读取配置、进程和固定日志|解释输出及范围查询边界。|
|Patch 检查与管理|`cc_patch.py`|检查、传输辅助文件、备份 / 恢复与热更|区分查询与写入，不能把链路成功说成游戏内生效。|
|服务生命周期|`start`、`shutdown`|启动、停止或强制结束服务|说明影响、前置状态与后置核验。|
|配置管理|`modify_game_config.sh`、`starttime`|修改远程游戏配置或时间文件|说明写入、备份、重载和回滚边界。|
|完整清档|`clear`|停服并调用数据清理流程|说明破坏性影响、备份、恢复和确认要求。|
|数据库数据清理|`clear_logic_game.py`、`clear_zone.py`、`cleardb.py`|删除或调整公共与业务数据|不公开敏感源码；要求独立数据范围、备份与恢复核验。|
|合服工具|`exc_server_merge.sh`、`stop_combine_tool.sh`|启动或停止合服工具|严格区分来源服启动与目标服停止 combine。|

## 概念调用关系

```text
服务器路由配置
├─ 基础查询、Patch、启动、关停、配置管理、清档与合服流程
└─ 内部目标解析（实际映射值不进入知识资料）

清档流程
├─ 服务停止 / 进程终止
├─ 逻辑游戏数据清理
├─ Zone 数据清理
└─ 可选的时间相关配置处理

服务生命周期
├─ 启动流程
└─ 正常、强制或批量关停流程
```

许多脚本还依赖目录外的远程控制、文件传输、配置修改、批量处理或专项工具。由于这些依赖不在当前资料范围内，不能仅根据此目录断言完整参数、影响、安全性或远端部署状态。

## 资料使用规则

1. 问答检索只读取 `knowledge/index.md` 与 `knowledge/docs/`。
2. `knowledge/scripts/`、原始 Excel 和真实 Linux 脚本不作为自动检索输入。
3. 知识文档解释用途、风险和验证边界，不授予执行权限。
4. 允许生成执行计划的范围只由 `config/muliu_script_catalog.md` 的精确合同决定。
5. 计划生成后仍须通过结构化校验、防火墙、路由校验和原请求人确认，才可能调用 Muliu。
6. 本地 catalog 或 manifest 不能代替 GS-1、Task 89、SSH 权限或目标服效果的实际核验。

## 风险分级原则

- 查询不等于绝对无副作用：检查流程可能涉及远程辅助文件传输。
- 启动、关停、时间设置、配置修改、Patch 与合服属于状态或配置变更。
- 清档、数据库清理和强制终止属于高影响操作，不能从知识问答直接升级为执行。
- 脚本、历史手册与部署版本出现差异时，应停止并以实际部署版本核验为准。
- 脚本退出成功不自动等于服务就绪、数据一致或游戏内已生效。
