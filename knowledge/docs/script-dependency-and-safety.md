# 脚本调用关系与安全边界

## 资料边界

本说明记录可见脚本之间的概念依赖，不包含内部地址、数据库连接、账号、凭据或目录外工具的实现细节。脚本阅读副本不能替代 Linux 已部署版本。

## 脚本类别

|类别|涉及资料|主要影响|当前机器人状态|
|---|---|---|---|
|基础状态查询|`basic_info.sh`|读取配置、进程和日志|已登记基础查询模式|
|Patch 检查与管理|`cc_patch.py`|检查、传输辅助文件，部分模式可变更或热更|仅登记单服检查模式|
|服务生命周期|`start`、`shutdown`|启动、停止或强制结束服务|不登记执行|
|配置管理|`modify_game_config.sh`、`starttime`|修改远程游戏配置或时间文件|不登记执行|
|完整清档|`clear`|停服并调用数据清理流程|不登记执行|
|数据库数据清理|`clear_logic_game.py`、`clear_zone.py`、`cleardb.py`|删除或调整公共与业务数据|不登记执行，且原始资料隔离|

## 概念调用关系

```text
服务器路由配置
├─ 基础查询、Patch、启动、关停、配置管理、清档流程
└─ 内部目标解析（实际映射值不进入知识资料）

清档流程
├─ 服务停止 / 进程终止
├─ 逻辑游戏数据清理
├─ Zone 数据清理
└─ 可选的时间相关配置处理

服务生命周期
├─ 启动流程
└─ 正常、强制或批量关停流程
```

许多脚本还依赖目录外的远程控制、文件传输、配置修改、批量处理或专项工具。由于这些依赖不在当前资料范围内，不能仅根据此目录断言其完整参数、影响或安全性。

## 资料使用规则

1. 问答检索只读取 `knowledge/index.md` 与 `knowledge/docs/`。
2. `knowledge/scripts/`、原始 Excel 和真实 Linux 脚本不作为自动检索输入。
3. 知识文档解释用途，不授予执行权限。
4. 允许生成执行计划的范围只由 `config/muliu_script_catalog.md` 决定。
5. 计划生成后仍必须通过结构化校验、防火墙和群内确认，才可能调用 Muliu。

## 风险分级原则

- 查询不等于绝对无副作用：例如检查流程可能涉及远程辅助文件传输。
- 启动、关停、时间设置和配置修改属于状态或配置变更。
- 清档、数据库清理和强制终止属于高影响操作，不能从知识问答直接升级为执行。
- 脚本、历史手册与部署版本出现差异时，应停止并以实际部署版本核验为准。
