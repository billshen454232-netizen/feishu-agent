# 木流操作流程（脱敏）

## 资料范围

本说明从历史操作手册中提取操作类别、风险与核对原则。它不包含原始门户链接、账号、人员、服务器标识或环境映射；也不是脚本执行许可。

## 操作类别

|操作类别|典型目的|风险等级|当前资料用途|
|---|---|---|---|
|基础信息与 Patch 检查|了解目标服状态、版本、日志或补丁情况|查询 / 检查|可用于解释；执行范围以独立执行资料为准|
|启动服务|恢复游戏或相关服务|服务状态变更|仅解释流程，不登记执行|
|关闭服务|正常停服、异常处置或批量停服|高风险服务中断|仅解释流程，不登记执行|
|清档与数据清理|为测试或环境重置清理数据|破坏性高风险|仅解释流程，不登记执行|
|开服时间管理|检查或调整测试环境时间相关配置|高风险配置变更|仅解释流程，不登记执行|
|赛季与剧本配置|调整目标服的游戏配置|高风险配置变更|仅解释流程，不登记执行|
|合服、调试或阈值类操作|历史手册中存在相关操作语义|待核实|当前目录缺少完整已审核入口，不提供执行说明|

## 使用原则

1. 先确认操作目标、当前环境状态和影响范围。
2. 变更、停服和清理类操作必须确认前置条件、备份与恢复方式。
3. 脚本阅读副本、历史手册和 Linux 已部署版本不一致时，以已审核的部署版本为准。
4. 历史手册中的操作名称或参数写法不能直接作为机器人执行参数。

## 与机器人执行的边界

知识问答可以解释某个操作通常用于什么、有哪些风险和应做哪些核对；只有 `config/muliu_script_catalog.md` 明确登记的脚本和参数模式，才能进入“生成计划 → 防火墙 → 群内确认”的执行流程。
