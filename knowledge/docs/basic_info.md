# basic_info.sh

## 用途

查询测试服基础状态。默认模式会输出剧本配置、代码版本、开服时间、Skynet 进程状态和启动检查结果。脚本还包含若干由位置参数触发的辅助查询分支。

机器人是否允许某一个精确调用，以 [../../config/muliu_script_catalog.md](../../config/muliu_script_catalog.md) 的当前合同为准；本文只解释脚本意图和结果边界。

## 调用形态

|调用形式|用途|影响与边界|
|---|---|---|
|`basic_info.sh <server_id>`|查询单服基础状态。|只读；默认输出不能单独证明本次起服完成。|
|`basic_info.sh <server_id> ctime`|查询服务器当前时间。|只读；需要由已部署脚本访问目标服。|
|`basic_info.sh ssinfo <scenario>`|查询剧本的服务器信息。|无目标服号的范围查询必须在计划根字段显式声明 `route_scope: cn` 或 `overseas`；该字段不是脚本参数。|
|`basic_info.sh ssnum <account_name>`|查询角色经历的赛季。|只读；依赖公共数据库查询工具。|
|`basic_info.sh <server_id> <user_id>`|查询玩家赛季分数相关信息。|只读；依赖已有 expect 脚本。|

不应因为脚本可能还支持其他参数而自行扩展计划；只有 catalog 中精确登记的形态可进入“计划 → 防火墙 → 确认 → 执行”流程。

## 默认输出内容

- 目标服务器的剧本配置；
- 当前代码版本；
- 开服时间戳及转换后的时间；
- Skynet 进程状态和进程组；
- 最近启动日志中的成功或常见失败提示。

未找到近期启动成功标记时，如果仍检测到 `game` 或 `zone` 进程，脚本可能返回警告而不是基础查询失败。该警告不能单独证明服务已经可用。

## 常见结果解释

- `服务器已正常关闭`：未发现目标 Skynet 进程；
- `开服成功`：最近 supervisor 日志中检测到启动成功标记；
- `警告：未检测到近期启动成功信息`：历史启动标记不在最近日志中，但仍检测到 `game` 或 `zone` 进程；
- `patch文件报错`：启动日志中发现 Patch 相关错误；
- `Listen error`：可能是端口占用，通常与开关服过快有关；
- `game_6 start fail`：剧本沙盒场景启动失败。

## 前置条件与数据边界

- 已部署脚本运行目录需要有 `config.ini`，用于解析内部 `<server_id>_game` 路由；路由原文不得进入 AI、飞书或 Git；
- 目标服务器需要可通过脚本已有的 SSH / 远程控制能力访问；
- 实际执行以 Linux 已部署版本为准，不以本仓库阅读副本推断远端版本或权限。

## 风险等级

**只读查询。** 它读取配置、进程和日志，但“只读”不等于已经完成远端部署或业务状态核验。
