# basic_info.sh

## 用途

查询测试服基础状态。默认模式会输出剧本配置、代码版本、开服时间、Skynet 进程状态和启动检查结果。

脚本还包含若干按位置参数触发的辅助查询分支，详见下方说明。

## 常用只读查询

```text
basic_info.sh <server_id>
```

示例：

```text
basic_info.sh 2003
```

在飞书中可描述为：

```text
查询 2003 服基础信息
查询 2003 服当前状态
查看 2003 服开服信息
查询 2003 服当前剧本
2003 服现在是什么剧本
查看 2003 服的剧本配置
```

当前机器人执行资料中已登记此模式。

## 默认输出内容

- 目标服务器的剧本配置；
- 当前代码版本；
- 开服时间戳及转换后的时间；
- Skynet 进程状态和进程组；
- 最近启动日志中的成功或常见失败提示。

## 辅助查询分支

|调用形式|作用|注意|
|---|---|---|
|`basic_info.sh <server_id> ctime`|查询服务器当前时间|通过远程控制台读取时间戳。|
|`basic_info.sh ssinfo <scenario>`|查询目标剧本的服务器信息|依赖公共数据库查询工具。|
|`basic_info.sh ssnum <account_name>`|查询角色经历的赛季|依赖公共数据库查询工具。|
|`basic_info.sh <server_id> <user_id>`|查询玩家赛季分数相关信息|依赖 expect 脚本。|

这些辅助分支尚未登记为机器人可执行计划；需要实际接入时，应先确认参数、输出和权限边界。

## 前置条件

- 脚本运行目录需要包含 `config.ini`，用于解析 `<server_id>_game`；
- 目标服务器需要可通过脚本已有的 SSH / 远程控制能力访问；
- 实际执行环境使用 Linux 已部署版本，不使用本目录的阅读副本。

## 常见结果解释

- `服务器已正常关闭`：未发现目标 Skynet 进程；
- `开服成功`：最近 supervisor 日志中检测到启动成功标记；
- `patch文件报错`：启动日志中发现 Patch 相关错误；
- `Listen error`：可能是端口占用，通常与开关服过快有关；
- `game_6 start fail`：剧本沙盒场景启动失败。

## 风险等级

**只读查询。** 脚本本身会远程读取配置、进程和日志，但默认模式不修改服务器数据。
