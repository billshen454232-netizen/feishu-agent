# clear

## 用途

对指定测试服执行清服流程。脚本会关闭游戏和 Zone 进程，并调用逻辑游戏数据与 Zone 数据清理脚本；可选地设置或删除开服时间配置。

## 调用形式

```text
bash clear <server_id> [by|noby]
```

示例：

```text
bash clear 2016
bash clear 2016 by
bash clear 2016 noby
```

## 参数说明

|参数|含义|
|---|---|
|`server_id`|目标测试服编号。|
|`by`|清服后设置指定的真实霸业开服时间。|
|`noby`|清服后删除开服时间配置。|

## 实际影响

此脚本会：

1. 停止游戏和 Zone 进程；
2. 清理逻辑游戏数据库数据；
3. 清理 Zone 数据库数据；
4. 按可选参数修改开服时间配置。

对特定服务器还会走专用逻辑。

## 前置条件

- 脚本依赖同目录 `config.ini`；
- 依赖清理逻辑游戏数据、清理 Zone 数据、关闭服务和远程配置修改等配套脚本；
- 真正执行只应使用已审核的 Linux 部署版本；历史阅读副本中的帮助文字与实际文件入口可能不完全一致，执行前必须以部署版本核验调用方式。
