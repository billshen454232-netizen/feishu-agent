# 测试环境摘要（脱敏）

## 资料范围

历史环境分布表记录了测试环境的占用、剧本归属和使用信息。精确服务器、人员、环境到服务器的映射及剧本绑定关系均属于内部运营拓扑，因此不写入本说明。

## 可用于问答的信息

测试环境可按开发、质量验证、区域测试、提审或前瞻等用途划分。无论具体类别如何，执行前都应核对当前占用、用途和正在进行的测试，避免误操作他人正在使用的目标。

## 操作前核对流程

1. 明确目标服务器标识和本次操作类型。
2. 向当前环境维护方核对该目标是否被占用，以及是否存在正在进行的验证、发布或合服流程。
3. 确认目标环境的剧本、时间或 Patch 前置条件是否与本次操作相符。
4. 对启动、停服、清档和配置变更，在群内说明影响范围和预计恢复方式。
5. 执行后用已审核的只读查询核对实际状态，并回传结果。

## 数据保护边界

```text
不得把原始环境分布表直接送入 AI；
不得在群消息中回显服务器—人员—环境或剧本的精确对应关系；
不得根据过期分布表猜测当前目标的归属或可操作性。
```

环境分布应由实际维护方持续更新；本说明只保留操作前核对原则。
