# 服务器路由配置

## 用途

脚本目录中的路由配置负责将逻辑服务器标识解析为内部服务目标。多个查询、启动、关停、配置修改和 Patch 工具都会依赖它定位目标环境。

## 可用于问答的信息

- 操作时需要提供正确的服务器标识；
- 脚本会通过统一路由配置解析目标，而不是由机器人在消息中拼接内部地址；
- 找不到服务器标识时，应停止执行并核对已部署配置，而不是猜测或替换目标；
- 路由配置的变更会影响多个脚本的实际作用目标，应作为独立配置变更处理。

## 数据保护边界

实际路由配置包含内部地址和环境映射，**不得**写入知识文档、AI 上下文、群消息、示例配置或 Git。

```text
不得把原始路由配置设为检索源；
不得根据知识文档猜测服务器映射；
不得把路由配置的修改混入普通脚本操作。
```

## 维护要求

- 路由配置由部署环境的维护者单独管理；
- 机器人计划只传递服务器标识，不回显内部目标；
- 任何执行失败都应以已部署环境的实际配置为准。
